# Code of Conduct

FootGlobe's project spaces should remain useful, technical and respectful.

Contributors are expected to discuss ideas and code without harassment, threats, discrimination, spam or deliberate disruption. Criticism should focus on the work, include enough context to be actionable, and avoid personal attacks.

Project maintainers may edit, hide or remove contributions that do not follow these expectations and may restrict participation when necessary to keep the project usable and safe.
